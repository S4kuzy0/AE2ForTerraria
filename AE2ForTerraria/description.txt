AE2 for Terraria

把 Minecraft 里 JEI 的「查」和 AE2 的「存 + 一键下单合成」搬进泰拉瑞亚。

查询
- 物品浏览器(默认按键 Tab,可在 设置→控制 里改),拖窗口边框就能移动 / 缩放,滚轮上下滚动
- 支持中文 / 英文 / 全拼 / 拼音首字母搜索,支持输入法直接打中文
- 左键或 R 看「来源」,右键或 U 看「用途」;覆盖窗口逐条看配方,点材料可跳转
- 悬停直接显示物品名 / 网络存量 / 配方数量;搜索框支持光标移动、Delete、Ctrl+A 与一键清空
- 窗口位置和大小会记住,每个窗口都有「⟲ 重置」;来源 / 用途是叠加窗口,不会顶掉底下的窗口
- 来源覆盖:所有合成配方分支、微光转化、怪物掉落(带掉落率)、NPC 商店(带价格)、宝藏袋内容
- 用途覆盖:所有消耗它的配方、用于召唤 Boss 的物品
- 顶部「物品 / 怪物」两个分类;怪物页可看所有 NPC(含 Boss)的属性、刷新条件、掉落与图鉴解锁状态
- 可按推进时间点(Boss 阶段)排序,状态栏显示你当前所处阶段
- 右下角扳手按钮(点亮变红 = 作弊模式):Shift + 左键直接拿物品

存储与自动合成
- ME 磁盘驱动器:插入磁盘提供容量并列出已存内容;驱动器不设上限,扩容只需换更高级的磁盘
- ME 存储单元:不需要磁盘的固定容量存储方块,可用升级件升到 Lv.3
- ME 分子装配室:装配室 + CPU 合体,一个方块完成整条自动合成;
  工作站槽位放满一排自动加一排;不需要写样板,配方条件与原料都满足就会自动制造;
  合成逐件计时,网络里多一个装配室就多一份并行进度
- ME 合成 CPU:合成队列,可排队、看进度、逐项取消、翻页
- ME 合成终端:网络物品列表 + 背包 + 配方 / 缺料 / 合成步骤预览,支持一键下单与任意数量
- 「存入全部」默认只扫主背包,不会把子弹和钱币一起存走(可在终端里切换)
- 驱动器里的内容是图标网格:左键取一叠、右键取全部
- ME 访问终端:右键绑定网络,之后按键(默认 P)在任意位置远程打开终端
- ME 掉落收集器:把附近掉落物直收进网络,右键方块可开它自己的过滤界面(每块独立)
- 过滤器是**可搜索的勾选网格**(绿边 = 已在清单里)
- 随身掉落磁铁(配置开关):站在网络旁边掉落物直接进网
- 合成队列:上限 24 项、暂停 / 继续、**保持库存**(缺了自动补货)
- 网络概览(按键 O):世界里的每个网络的位置 / 容量 / 类型数,可以起名字
- 4 个成就;两个主窗口可以同时开(查来源不会顶掉终端)
- ME 存储总线:贴着原版箱子,导入 / 导出双向切换
- 词缀(前缀)是完整身份的一部分:带词缀的物品有独立格子、tooltip 显示词缀名,
  取出 / 拆方块 / 总线导出都不会洗掉词缀;配方也能消耗带词缀的原料
- ME 网络线缆 + 无线桥接器:线缆便宜延伸网络,同频道的两个桥接器把两块网络连成一个

多人联机
- 服务器权威 + 快照同步:终端存取 / 取出全部 / 下单 / 队列 / 工作站 / 磁盘 / 收集器配置 /
  桥接器频道 / 存储总线模式全部接入;远程终端会收到整网汇总
- 多人权限:每个网络有所有者,权限分只读 / 可存取 / 可管理三级;没有权限会被服务端拒绝并提示
- 容量告警、网络概览占用条、清单导入导出、队列重排、7 个成就
- 存取审计(谁取走了什么)、合成产出可选给玩家、概览方块构成、内容界面排序、终端多选、
  随身磁铁按键开关(M)、帮助分 4 页、成就进度提示
- 概览健康检查、网络之间直接转移、物品级锁定、网络分裂/合并提示、容量历史趋势、
  双击取全部同种、Shift+右键存全部同种、9 个成就、界面性能优化(账本版本号 + 文本缓存)

配置
- 游戏内 设置 → 模组配置 → AE2 for Terraria:
  作弊模式、详细日志、每件合成耗时、新收集器的默认半径 / 黑白名单 / 过滤清单、自定义 Boss 顺序
