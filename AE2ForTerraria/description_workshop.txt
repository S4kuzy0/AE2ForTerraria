## AE2 for Terraria

把 Minecraft 里 **JEI 的查询能力** 和 **AE2 的存储 + 一键下单合成** 移植到泰拉瑞亚。

### 查询
- **物品浏览器**(默认按键 **Tab**,可在 设置 → 控制 里改),拖窗口边框就能移动 / 缩放,滚轮上下滚动
- 支持 **中文 / 英文 / 全拼 / 拼音首字母** 搜索;打开窗口就能直接打字,支持输入法
- 左键或 **R** 看「来源」,右键或 **U** 看「用途」,以 JEI 式覆盖窗口逐条显示,点材料可跳转
- **悬停直接显示物品名 / 网络存量 / 配方数量**;数量按 12K / 3.4M 缩写
- 搜索框支持光标移动、Delete、Ctrl+A 与一键清空,右上角「? 帮助」列出全部快捷键
- **窗口位置和大小会记住**,每个窗口都有「⟲ 重置」
- **来源 / 用途是叠加窗口**:开着终端也能查来源,不会顶掉底下的窗口
- **来源**覆盖:合成配方(所有分支)、微光转化、怪物掉落(带掉落率)、NPC 商店(带价格)、宝藏袋 / 宝箱内容
- **用途**覆盖:消耗它的所有配方、用于召唤 Boss 的物品
- 顶部 **物品 / 怪物** 两个分类;怪物页可查看所有 NPC(含 Boss)的生命 / 防御 / 接触伤害、
  **刷新条件**、**掉落表**,以及图鉴是否解锁
- 可按 **推进时间点(Boss 阶段)** 排序;状态栏显示你当前所处阶段
- 装了 BossChecklist / 灾厄 / Fargo 会自动采用它们的顺序;装别的模组包时用推断引擎补全

### 存储与自动合成
- **ME 磁盘驱动器**:插入不同级别的磁盘提供容量,并且**列出已存了什么**。
  物品存在驱动器里,磁盘只负责容量,所以可以随时换盘
- 驱动器里的内容现在是**图标网格**:左键取一叠、右键取全部
- **ME 存储单元**:不需要磁盘的固定容量存储方块,可用**升级件**升到 Lv.3
- **ME 分子装配室**:分子装配室与合成 CPU 的集合体,一个方块就能跑完整条自动合成。
  工作站槽位放满一排会自动加一排;**不需要写样板**,只要配方条件与原料都满足就会自动制造。
  合成**逐件计时**,网络里多摆一个装配室就多一份并行进度
- **ME 合成 CPU**:给网络加一个合成队列,可排队、看进度条、逐项取消、翻页查看长队列
- **ME 合成终端**:网络物品列表 + 背包 + 配方 / 缺料 / **合成步骤预览**,
  缺料会标注**获取途径**与**时间点**;支持一键下单、任意数量、收藏与排序
- **ME 访问终端**:右键绑定网络,之后按键(默认 P)在任意位置远程打开终端
- **ME 掉落收集器**:把附近掉落物直收进网络,右键打开**它自己的**过滤清单(每块独立)
- **随身掉落磁铁**(配置里开关):站在网络旁边,掉落物直接进网,不用摆收集器
- **合成队列可控**:上限、暂停 / 继续、**保持库存**(缺了自动补货)
- **网络概览(按键 O)**:列出世界里每个网络的位置 / 容量 / 内容量,可以给它们起名字
- **4 个成就**,两个主窗口可以同时开(查来源不会顶掉终端)
- **存取审计**:每个网络记录最近 40 条「谁取/存/下单了什么」,在权限页可查
- **合成产出可选给玩家**:下单造出来的东西直接落到你身上,不用再跑回去取
- **网络概览显示方块构成**(驱动器 / 单元 / 终端 / 装配室 / CPU / 收集器 / 总线 / 桥接 / 线缆)
- **内容界面可排序**;**终端支持多选批量取出**;**M 键开关随身磁铁**;**帮助分 4 页**
- **概览健康检查**(直接说缺什么导致什么不能用)、**网络之间直接转移**、**物品级锁定**、
  **分裂/合并提示**、**容量历史趋势**、**双击取全部同种物品**
- 「存入全部」默认**只扫主背包**,不会把子弹和钱币一起存走(可在终端里切换)
- **ME 存储总线**:贴着原版箱子放置,导入 / 导出双向切换,**带分区清单**(白/黑名单,可搜索勾选)
- **词缀是完整身份**:带词缀的物品在网格里有独立格子、tooltip 显示词缀名,
  取出 / 拆方块 / 总线导出都不会洗掉词缀;配方也能消耗带词缀的原料
- **ME 网络线缆 + 无线桥接器**:线缆便宜延伸网络;同频道的两个桥接器把两块网络连成一个,
  方块上方会显示频道号

### 多人联机
- **服务器权威 + 快照同步**:客户端发请求,服务器执行并广播结果
- **多人权限**:每个网络有所有者,权限分只读 / 可存取 / 可管理三级,在「网络概览 → 权限设置」里分配;
  没权限的请求会被服务端拒绝并提示
- 终端存取 / 取出全部 / 下单 / 合成队列 / 装配室工作站 / 磁盘插拔 / 存储单元升级 /
  收集器配置 / 桥接器频道 / 存储总线模式全部接入
- 用远程终端时服务器会额外发一份**整网汇总**,人在远处也能看到网络库存

### 配置(游戏内 设置 → 模组配置 → AE2 for Terraria)
- **作弊模式开关**:物品浏览器右下角的扳手(点亮变红),默认开启
- **详细日志**:索引统计 / 图鉴诊断 / 商店扫描样本,排查问题用,默认关闭
- **每件合成耗时(tick)**、新收集器的默认半径 / 黑白名单 / 过滤清单
- **自定义 Boss 顺序**:每行一个阶段名,从上到下就是先后顺序
