# AE2 for Terraria 玩家指南

适用源码版本：**0.26.2**。版本号以 [build.txt](build.txt) 为准；安装与启动见[仓库 README](../README.md#安装与启动)。

## 从查询开始

按默认 **Tab** 打开物品浏览器，搜索物品或切换 NPC 目录。可以按名称、全拼、拼音首字母搜索，并使用分类、模组等条件缩小结果。选择条目后查看配方、材料、用途、合成树或掉落详情。

物品格统一使用细黑边，底色和角标表示悬停与选中状态。怪物／NPC 目录采用紧凑方格，默认按图鉴顺序排列；悬停查看完整名称与来源模组，点击打开详情。窗口四边不显示悬停高亮，拖动和缩放方式沿用原操作。

查询显示的是当前已加载内容。合成树属于规划说明；某些特殊配方不能自动执行。Boss 进度排序含来源数据和推断，不能将它理解为所有模组的精确解锁顺序。

## 建立存储网络

准备 ME 磁盘驱动器、一块存储磁盘和 ME 访问终端。按游戏中显示的配方制作，将设备放在同一网络中，距离较远时用 ME 网络线缆连接。

1. 右键驱动器，插入磁盘。物品保存在驱动器实体中，磁盘只提供容量。
2. 右键访问终端，查看已储存物品并绑定该网络。
3. 使用存入、取出或背包槽位操作。批量存入保护收藏物品，默认只处理主背包；含弹药、钱币的范围需显式选择。
4. 绑定后按默认 **P** 远程打开访问终端。绑定按世界区分；失效绑定和权限变更会影响访问。

也可使用自带容量的 ME 存储单元；它不需要磁盘，可用存储升级件升级。

### 当前磁盘容量

| 游戏显示名 | 对应的历史内部类名 | 每块磁盘提供的类别位 |
| --- | --- | --- |
| ME 存储磁盘（\(32\) 类） | `MEDisk1K` | \(32\) |
| ME 存储磁盘（\(64\) 类） | `MEDisk4K` | \(64\) |
| ME 存储磁盘（\(128\) 类） | `MEDisk16K` | \(128\) |
| ME 存储磁盘（\(256\) 类） | `MEDisk64K` | \(256\) |

普通磁盘每种身份的数量上限为 \(2{,}147{,}483{,}647\)，各类别互不共用这一数量额度；同一驱动器中的类别位累加。词缀或自定义数据不同的物品分别占类。内部类名沿用旧版本，当前磁盘不再按旧版字节预算限制入库。

驱动器有 \(10\) 个磁盘槽。移出或替换磁盘前会检查剩余容量，不能用换盘使已有内容丢失。数字奇点提供逻辑容量扩展，但仍受整数表示、内存和网络实现边界约束，不能理解为物理资源无限。

存储单元仍使用字节预算，类别上限为 \(24\)，三级容量分别为 \(8192\)、\(32768\)、\(131072\) 字节。它与驱动器的磁盘容量规则不同。

## 开始自动合成

在已连接的存储网络中加入 **ME 合成终端**，把需要的工作台物品放入配方页底部的槽位。“合成列表”上方可以切换可合成／全部配方，任务入口管理队列。新版终端已经内置队列和执行功能，新网络不必另接独立 CPU 或分子装配室。

在配方页选择目标和数量，查看材料、缺料及合成树，再下单。任务页用于观察状态、暂停或取消；保持库存页用于在库存低于目标时补货。工作站、材料、原配方环境条件和网络权限仍然生效。空间不足时任务会等待，失败的事务不得先扣掉材料。

“新增制作”和“保持库存”语义不同：新增制作要求增加产物，已有目标物不能抵消订单；保持库存会计入现有库存及已排队数量。补货产出进入网络。

独立 CPU 与分子装配室保留旧队列、工作站和目标的兼容路径。连接新版终端后由终端统一调度；不要为安装新版而拆除带物品的旧设备。旧常量 `MaxJobs`、`MaxKeep` 已不作为当前队列和库存目标的硬上限。

## 其他设备

| 设备 | 用途与注意事项 |
| --- | --- |
| 网络线缆 | 连接 ME 设备，本身不提供存储容量 |
| 无线桥接器 | 同频道且启用的桥接器连接网络；可查看、切换频道或断开，频道相同可能合并原本独立的网络 |
| 掉落收集器 | 吸收附近允许的掉落物；每个设备有独立过滤条件 |
| 存储总线 | 接入原版箱子系统，支持过滤、导入与导出；不接入第三方存储模组容器 |
| 网络概览 | 查看容量和组成、命名、权限、物品锁定、审计与网络转移 |

## 默认快捷键

| 按键 | 功能 |
| --- | --- |
| Tab | 打开查询窗口；已有 AE 窗口打开时关闭窗口栈 |
| P | 远程打开已绑定的访问终端 |
| O | 打开或关闭网络概览 |
| M | 切换自己的随身磁铁；还需服务器配置总开关允许 |

快捷键可在游戏控制设置中修改。搜索输入、输入法组合和窗口焦点会影响按键处理。访问终端负责存取；合成终端负责配方、任务、工作站与补货，不能把两者的界面功能混为一谈。

## 配置和使用边界

模组配置为服务器侧配置。掉落收集器默认开启，随身磁铁总开关默认关闭，详细日志默认关闭，溢出掉落销毁默认关闭。作弊入口默认允许，但还需要在浏览器中实际启用作弊状态；多人使用应遵循服务器设置。

- 保持库存和手工订单需要满足实际工作站与环境条件。
- 特殊合成、材料消耗回调或自定义创建规则可能提示“请手动制作”。
- 权限身份沿用 Terraria 玩家名和原生同步边界，不构成完整反作弊系统。
- Recipe Browser 全功能对等、全量第三方配方兼容及所有输入法场景尚未完成统一验收。

数据保存位置、回归检查与常见故障见[设计说明](../docs/design.md)和[维护手册](../docs/maintenance.md)。
