# AE2 for Terraria 玩家指南

适用源码版本：**0.27.2**。版本号以 [build.txt](build.txt) 为准；安装与启动见[仓库 README](../README.md#安装与启动)。

## 从查询开始

所有窗口初始大小统一为 \(475 \times 350\) 个游戏 UI 逻辑像素，顶部功能标签高 \(22\)，与 Recipe Browser 默认窗口接近。0.26.5 首次打开会使用新默认布局，旧布局记录仍保留；之后移动、缩放会继续保存。只拖右下角斜线缩放，其他边框和空白处用于移动。

分类和子分类使用游戏物品或 NPC 立绘，悬停显示名称，按可用宽度换行；没有新增分类。JEI 与访问、合成终端的物品格为 \(44 \times 44\) 个逻辑像素，JEI 网格延伸到底部，未满整行的部分也会裁剪显示并响应可见区域的点击。合成工作台槽位在配方目录底部，打开物品详情后将空间让给配方，返回目录即可管理工作台。

分类只保留“盔甲”，悬停套装组件可查看对应基础套装效果。母分类用铜短剑图标表示“全部”，悬停查看名称；子分类不再重复“全部”。点击父分类恢复该类别全部物品，点击顶端母页也可恢复全部类别。滚动条在右下角缩放手柄上方留有独立间隙。

配方组材料显示通用名称，图标及“替代”菜单仍可查看具体成员。查询树和收藏树遇到循环转换时先尝试其他配方，无法展开时只保留最初的缺料节点。收藏树可拖动标题移动并保存位置，持续使用最近打开终端的授权库存；尚未开过终端时使用角色绑定的访问终端，无可读网络时参考背包。按收藏顺序共享抵扣库存，隐藏已齐的材料及下级分支，保留根目标并显示“材料已齐”。这些数量只是查询预览，不会移动任何物品。

套装索引按帧查询并缓存，读取声明的基础说明，不运行真实装备更新、召唤或战斗效果；当前穿戴组件可补充显示游戏已算出的实时奖励。依赖特殊代码计算且无法安全读取的说明会明确提示，不编造内容。

按默认 **Tab** 打开物品浏览器，搜索物品或切换 NPC 目录。可以按名称、全拼、拼音首字母搜索，并使用分类、模组等条件缩小结果。选择条目后查看配方、材料、用途、合成树或掉落详情。

物品格统一使用细黑边，底色和角标表示悬停与选中状态。怪物／NPC 目录采用紧凑方格，默认按图鉴顺序排列；悬停查看完整名称与来源模组，点击打开详情。窗口四边不显示悬停高亮，拖动和缩放方式沿用原操作。

查询显示的是当前已加载内容。合成树属于规划说明；某些特殊配方不能自动执行。Boss 进度排序含来源数据和推断，不能将它理解为所有模组的精确解锁顺序。

## 终端操作

合成终端窗口显示“终端”，同时提供存取与合成。目录默认“储存＋可合成”，点击范围按钮依次切换全部配方、已储存、可合成；可合成只含已核验整棵材料树与条件的目标，缓存计算中的项目不会提前冒充可合成。完整身份不同的库存分别显示。

普通左键点击物品打开原有配方子页，双击不取物。子页下方可指定数量、取出、合成或维持库存，左上角返回恢复目录；Shift＋左键仍可快速取出一叠。手持物品点击目录可存入，原版背包中未被前方窗口遮挡的槽位支持 Shift 存入；没有额外内嵌背包。底部工作台槽位与任务入口保留。旧访问终端使用同一详情页提供取出操作，合成操作由合成终端提供。

## 建立存储网络

准备 ME 磁盘驱动器、一块存储磁盘和 ME 合成终端；旧 ME 访问终端继续支持存取和绑定。按游戏中显示的配方制作，将设备放在同一网络中，距离较远时用 ME 网络线缆连接。

1. 右键驱动器，插入磁盘。物品保存在驱动器实体中，磁盘只提供容量。
2. 右键终端查看库存；使用访问终端可绑定该网络，合成终端同时支持制作。
3. 使用存入、取出或背包槽位操作。批量存入保护收藏物品，默认只处理主背包；含弹药、钱币的范围需显式选择。
4. 绑定后按默认 **P** 远程打开访问终端。绑定按世界区分；失效绑定和权限变更会影响访问。

也可使用自带容量的 ME 存储单元；它不需要磁盘，可用存储升级件升级。

### 当前磁盘容量

| 游戏显示名 | 对应的历史内部类名 | 每块磁盘提供的类别位 |
| --- | --- | --- |
| ME 存储磁盘（\(32\) 类） | `MEDisk1K` | \(32\) |
| ME 存储磁盘（\(64\) 类） | `MEDisk4K` | \(64\) |
| ME 存储磁盘（\(128\) 类） | `MEDisk16K` | \(128\) |
| ME 存储磁盘（\(256\) 类） | `MEDisk64K` | \(256\) |

普通磁盘每种身份的数量上限为 \(2{,}147{,}483{,}647\)，各类别互不共用这一数量额度；同一驱动器中的类别位累加。词缀或自定义数据不同的物品分别占类。内部类名沿用旧版本，当前磁盘不再按旧版字节预算限制入库。

驱动器有 \(10\) 个磁盘槽。移出或替换磁盘前会检查剩余容量，不能用换盘使已有内容丢失。数字奇点提供逻辑容量扩展，但仍受整数表示、内存和网络实现边界约束，不能理解为物理资源无限。

存储单元仍使用字节预算，类别上限为 \(24\)，三级容量分别为 \(8192\)、\(32768\)、\(131072\) 字节。它与驱动器的磁盘容量规则不同。

## 开始自动合成

在已连接的存储网络中加入 **ME 合成终端**，把需要的工作台物品放入配方页底部的槽位。物品网格左上角可以切换可合成／全部配方，任务入口管理队列。新版终端已经内置队列和执行功能，新网络不必另接独立 CPU 或分子装配室。

从目录打开物品后，“返回”直接回目录；详情内继续点击材料、切换页签或配方时，“返回／前进”依次恢复这些页面。每次重开 JEI 都先显示目录。“历史”保留最近十次物品、NPC 和详情页浏览，跨游戏重启保存，并与“最近查看”排序共用记录；历史恢复时保留数量与查看位置。

按 **Alt＋左键** 收藏或取消，已收藏物品带金色星标；鼠标指向物品时按 Alt 会显示原版星形光标。详情标题和产出图标会收藏当前选中的配方及数量；筛选菜单保留“已收藏”条件。Alt 不再从访问终端取半组物品，Shift 取一叠和 Ctrl 多选继续保留。

右上角收藏合成树默认立即显示，用连线区分父子材料，拖动标题移动，滚轮可查看末尾，Shift＋滚轮横向查看深层分支。收藏树会抵扣每次重复需求，普通查询树的重复分支可通过引用跳转；循环转换不展开，数量溢出明确标记。眼睛按钮切换“始终显示／仅打开背包时显示”，位置与收藏一起保存。未加载的模组条目仍保留，也可用 Alt＋左键取消。收藏树遵守 AE 窗口的遮挡顺序；与前方窗口重叠时，可拖动面板或窗口查看。关窗后继续读取最近终端的授权库存，尚未选择终端时读取角色绑定，网络不可读时参考背包；它是查询预览，不代替实际合成条件检查。

配方、来源、用途、合成树与返回按钮同排。材料按“立绘、名称、需求、缺少”单行显示，名称较长时可悬停查看全文。工作站与环境条件合并显示，采用配方原本要求的工作站，多个独立必需站仍全部保留；长内容在同一页面连续滚动。祭坛等不可放置工作站使用游戏地图名称。

在任一终端手持物品移入网格时，可预先查看接收数量或拒绝原因。类别满时新物品保留原处，已有类别仍可接收；可照常右键驱动器加盘，再存入刚才的物品。过滤拒绝和单类数量上限会单独说明。联机以服务器复核结果为准。

驱动器打开时会同时打开原版背包，不再显示第二份小背包。用原版背包拿起磁盘，再点击驱动器槽位取放；窗口重叠处仍只有最前面的 AE 窗口响应。

手动合成在条件齐全时点击即执行整批事务，并显示“合成完成”和本单需求数量。后台等待任务在最后一批完成时通知下单玩家；暂停、缺料、工作站、环境或产出容量阻塞仍会保留任务并说明原因。复杂配方仍需实际规划计算，不增加人工合成计时。

在配方页选择目标和数量，查看材料、缺料及合成树，再下单。任务页用于观察状态、暂停或取消；保持库存页用于在库存低于目标时补货。工作站、材料、原配方环境条件和网络权限仍然生效。空间不足时任务会等待，失败的事务不得先扣掉材料。

“新增制作”和“保持库存”语义不同：新增制作要求增加产物，已有目标物不能抵消订单；保持库存会计入现有库存及已排队数量。补货产出进入网络。

独立 CPU 与分子装配室保留旧队列、工作站和目标的兼容路径。连接新版终端后由终端统一调度；不要为安装新版而拆除带物品的旧设备。旧常量 `MaxJobs`、`MaxKeep` 已不作为当前队列和库存目标的硬上限。

## 其他设备

| 设备 | 用途与注意事项 |
| --- | --- |
| 网络线缆 | 连接 ME 设备，本身不提供存储容量 |
| 无线桥接器 | 同频道且启用的桥接器连接网络；可查看、切换频道或断开，频道相同可能合并原本独立的网络 |
| 掉落收集器 | 吸收附近允许的掉落物；每个设备有独立过滤条件 |
| 存储总线 | 接入原版箱子系统，支持过滤、导入与导出；不接入第三方存储模组容器 |
| 网络概览 | 查看容量和组成、命名、权限、物品锁定、审计与网络转移 |

## 默认快捷键

| 按键 | 功能 |
| --- | --- |
| Tab | 打开查询窗口；已有 AE 窗口打开时关闭窗口栈 |
| P | 远程打开已绑定的访问终端 |
| O | 打开或关闭网络概览 |
| M | 切换自己的随身磁铁；还需服务器配置总开关允许 |

快捷键可在游戏控制设置中修改。搜索输入、输入法组合和窗口焦点会影响按键处理。访问终端负责存取；合成终端负责配方、任务、工作站与补货，不能把两者的界面功能混为一谈。

## 配置和使用边界

模组配置为服务器侧配置。掉落收集器默认开启，随身磁铁总开关默认关闭，详细日志默认关闭，溢出掉落销毁默认关闭。作弊入口默认允许，但还需要在浏览器中实际启用作弊状态；多人使用应遵循服务器设置。

- 保持库存和手工订单需要满足实际工作站与环境条件。
- 特殊合成、材料消耗回调或自定义创建规则可能提示“请手动制作”。
- 权限身份沿用 Terraria 玩家名和原生同步边界，不构成完整反作弊系统。
- Recipe Browser 全功能对等、全量第三方配方兼容及所有输入法场景尚未完成统一验收。

数据保存位置、回归检查与常见故障见[设计说明](../docs/design.md)和[维护手册](../docs/maintenance.md)。
