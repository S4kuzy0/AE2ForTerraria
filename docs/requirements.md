# 需求与验收标准

基线：源码 0.27.3；核对日期：2026-10-18（北京时间）。本文件规定当前维护范围的功能与验收条件；实际验证结果统一见[维护手册](maintenance.md#已知验证基线)。

## 目标与范围

窗口初始尺寸统一为 Recipe Browser 默认的 \(475 \times 350\) 个逻辑像素，顶部标签高 \(22\)；旧布局一次性切换到新默认尺寸，之后继续保存个人调整。仅右下角斜线缩放，其余边框移动。按住、连续拖动、释放手柄均不得在遍历子控件时重排同一集合；验证必须运行完整窗口更新，不能只单独调用手柄。

在实际启用模组环境中提供可查询、可存取、可自动制作、可管理的 ME 网络，优先保证物品数据与存档安全。保留旧设备和数据的兼容读取，减少玩家重复操作，并让失败原因可理解。

需求以当前源码和已确认边界为基础。新增功能、变更范围和验收结果应同步更新此文档；未经确认的想法不能写成已承诺功能。

## 功能要求

| 标识 | 要实现的行为 | 验收标准 | 当前实现入口 |
| --- | --- | --- | --- |
| QUERY | 搜索加载内容，查看来源、用途、配方和 NPC | 名称、拼音、模组与分类筛选正确；详情可导航；材料、工作站、条件及掉落采用真实索引；未知来源有明确表现 | `SearchUIState`、`UIBrowserDetails`、`GameDataIndex`、`RecipeIndex` |
| STORAGE | 跨设备集中存取，保留完整物品身份 | 词缀与自定义数据不混淆；单格、同类、批量操作符合选择范围；收藏保护、部分成功、满容量失败均保持数量守恒 | `ItemKey`、`ItemPersistence`、`StorageLedger`、`StorageOperations` |
| CAPACITY | 磁盘类别容量、存储单元升级和换盘保护 | 与玩家指南容量一致；超额旧数据仍可读取、取出；不能因降级、移盘或升级失败丢失库存 | `MEStorageDisk`、`MEDiskDriveEntity`、`MEStorageUnitEntity` |
| NETWORK | 物理连通、无线连接和拓扑变化 | 多格设备以原点定位；放置、拆除、频道或启停变化使缓存失效；合并、拆分后策略不能被绕过 | `MachineTiles`、`MENetwork`、`WirelessRegistry`、`NetworkRegistry.Topology` |
| ACCESS | 存取与远程访问 | 访问终端只展示对应可读库存；等待或拒绝时不能使用陈旧库存；绑定按世界区分，撤权后停止操作 | `MEPlayer`、`TerminalReadState`、`TerminalPolicyState` |
| CRAFT | 内置自动合成和准确缺料分析 | 新网络无需额外 CPU 或装配室；配方组、替代材料、中间产物和批量产出共享库存计数；新增制作不被现有成品抵消；不满足条件或特殊规则时明确拒绝 | `CraftPlanning`、`RecipeExecutionPolicy`、`TerminalCraftingExecutor` |
| QUEUE | 管理任务和保持库存 | 暂停、取消、排序和保存重载一致；缺料任务不永久堵住其他任务；补货计入现有与在途数量；旧队列可使用 | `MECraftingCpuEntity`、`MECraftingTerminalEntity` |
| TRANSACTION | 扣料与产出整体完成 | 提交前复核材料、容量、权限、条件、任务和连接；失败不改变任意一边；只容纳一批时可按逐批规则继续 | `StorageTransaction`、`TerminalCraftingExecutor` |
| AUTOMATION | 掉落物与原版箱子交换 | 过滤、身份、容量、锁定和箱子变化正确处理；重建或回调异常不先扣除源物品 | `MEDropCollectorEntity`、`MEStorageBusEntity`、`MEPlayer` |
| SECURITY | 权限、锁定与审计 | 只读用户不能存取或改配置；网络转移检查双方权限；未授权者不能取得管理信息；撤权快照清除陈旧状态 | `NetworkRegistry`、`MENet.Access`、`MENet.Network` |
| MULTIPLAYER | 服务端执行与完整同步 | 客户端发送意图，服务端检查真实状态；重复、过期、截断包不能重复扣账；远程访问不依赖本地完整实体；客户端与服务器版本一致 | `MENet` 各分片、`InventoryTransactionInputSystem` |
| UI | 直观操作与稳定窗口输入 | 合成终端兼有存取与合成，配方保留子页；普通左键打开子页，双击不取物；搜索、数量、滚动和弹层不抢输入；不同分辨率及缩放下可访问控件和最后一条材料；中文长文本不重叠 | `UISystem`、`AEUiSession`、`MovableWindowState`、UI 控件 |
| PERSISTENCE | 分开保存世界、角色与本地偏好 | 重进世界保留账本、队列和策略；保存稳定身份；缺失模组保留占位；读取旧数字格式；布局与收藏不作为服务器配置上传 | `ItemPersistence`、`TagCompat`、实体保存、`MEPlayer`、`BrowserFavorites` |

上述入口表说明已有源码实现，不意味着所有验收条件已经通过全部游戏场景测试。

## 共同验收条件

界面补充验收：窗口四边及标题拖动条不显示悬停高亮，物品格使用细黑边；合成页移除“合成列表”标题和底部数量、工作站标题，可合成筛选左对齐，让网格延伸至工作台槽位上方。保留工作台槽位及权限失败提示。终端显示范围下拉仅含“已储存”“可合成”“已储存/可合成”；排序也采用下拉，打开菜单不改变当前选项。窗口采用泰拉瑞亚蓝色，细黑物品边框和无悬停高亮的窗口边缘保留。旧访问终端隐藏新制作、研究和 AE 查询入口，旧物品、方块及绑定仍可读取使用。NPC 目录采用方形立绘格、悬停名称与来源、图鉴默认顺序，并继续包含敌对生物、城镇 NPC 和小动物。

详情内导航应恢复页面、配方、数量及滚动位置，新的浏览分支清除前进历史。目录新选物品的返回路径以目录为根，不能插入上一次关闭的物品。最近十次浏览独立持久保存，跨重启保留；每次打开 JEI 先显示目录，历史菜单和最近查看排序共用这些记录。NPC 详情不能继续对前一个物品下单。

收藏按钮全部移除，以 Alt＋左键、星形光标及金色物品标记操作收藏。保存当前选中配方和数量，兼容旧收藏，并保留暂时禁用的模组引用。收藏树可拖动标题，位置和眼睛偏好跨重启保存，切换常显与仅背包显示。当前终端优先，关窗后保留最近终端，首次使用角色绑定；仅使用授权库存，不可读时明确回到背包。共享预览库存，隐藏已齐材料及子分支，根目标保留并显示材料状态。重复需求必须继续抵扣，不因引用而漏算；循环转换从最初缺料节点下方整段隐藏，先尝试非循环替代。查询树可复用显示引用。它是客户端查询，不构成库存、权限或合成执行依据。

分类合并为单个“盔甲”，母分类保留铜短剑“全部”图标，子分类不重复“全部”；点击父分类或顶级母页恢复对应全部范围。悬停套装组件查询基础效果；不得为展示说明运行真实装备更新或战斗效果，无法独立读取的动态说明须明确提示。配方组显示通用名称，保留成员图标和替代菜单。JEI 和两类终端物品格保持现有尺寸及半行裁剪、命中；滚动条与下移的角落缩放手柄保留独立间隙。

存入前应能看到游标物品是否可接收；拒绝时区分类别、单类数量和过滤原因，物品留在原处。类别满时仍可存入已有身份、打开驱动器和增加磁盘；旧超额存储不能截断，允许逐张扩容恢复。客户端预测不替代服务器权限与容量验证。

驱动器移除内嵌背包，打开原版背包供直接拿盘，内容列表使用腾出的空间；重叠输入不能穿透。手动合成条件齐全时，在提交调用返回前完成整批扣料和入库并给出完成提示；新单不能并入旧暂停任务而被阻塞。受阻任务保留，最终完成时仅通知下单玩家，不对匿名补货持续弹提示。

- 数量守恒：核对源、目标及余量，不能只观察状态文字。
- 数据保护：使用隔离夹具或专用测试世界、角色，先建立恢复点，不覆盖原始存档。
- 环境真实：使用游戏实际存档目录和启用列表；服务端测试只证明它实际加载的内容。
- 证据明确：编译、静态资源、核心回归、UI 绘制、游戏交互和真实联机分别报告，不能互相替代。
- 搜索预算：超出预算时说明有限搜索或复杂度原因，不当作已证明无法合成。
- 文档一致：界面、容量、协议、数据结构或安装方式改变时，同时更新对应指南、设计与维护说明。

## 既定边界

- 存储总线只接原版箱子系统，不计划接入第三方存储容器。
- Boss 阶段推断是查询辅助信息，未知来源保留未知状态。
- 特殊合成回调不能安全表达为事务时，采用手动制作提示。
- 内存、传输和整数表示仍有实际边界，数字奇点不消除这些边界。
- 原生玩家身份与物品同步不等同于完整反作弊。
