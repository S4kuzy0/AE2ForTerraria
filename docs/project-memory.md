## 已确认目标与约束

- 以真实启用模组环境开发和验证，实际启用列表是依据；不能用曾经记录的模组数量替代检查。
- 存储总线只支持原版箱子系统，这是允许的设计，不列入第三方存储接入计划。
- 在已授权范围内默认直接实施 UI 与非 UI 更新；用户仅规划、仅预览或使用 `/plan` 时遵从当次范围。历史必须预览后安装的规则已于 2026-10-10 取消。
- 代码版本完成后递增版本、构建安装并验证；纯文档与版本管理配置变更不发布模组新版本。
- 文档随代码维护，记录关键知识即可，不为简单函数堆积说明。界面操作和报错反馈用清楚的中文。
- 使用现有私有仓库 [S4kuzy0/AE2ForTerraria](https://github.com/S4kuzy0/AE2ForTerraria)，助手完成更新后自动提交、推送并核验。
- 存档、个人配置、备份、产物、日志、提取的预览素材与助手指令文件不上传。指令文件只保留本地；此前误上传历史已按用户要求清理，不得重新引入旧历史。
- 自动上传是助手处理更新时的步骤，不是外部工具每次保存后的后台监控。

## 技术与决策

| 事实或决定 | 理由、依据与影响 |
| --- | --- |
| C# 12 / .NET 8 / tModLoader | 当前模组项目配置；.NET 9 仅用于部分历史独立 harness，不是游戏运行要求 |
| 继续使用 tML 生命周期和直接模块调用 | 既有架构记录选择可维护的边界，未引入容器、数据库或独立服务器；不要无依据扩大技术栈 |
| 物品账本存在设备实体，磁盘只供容量 | 换盘不迁移物品；必须检查剩余容量，不能把盘当成携带库存的物品 |
| 身份包含规范化自定义数据，保存采用 ItemIO | 避免词缀/自定义物品合并，避免仅按会变化的运行时编号存档；旧数字记录仍有兼容边界 |
| 合成先规划、再复核、事务整体提交 | 输出空间、权限或回调变化时不丢材料；超出规划预算保留有限搜索状态 |
| 新版合成终端内置队列和工作站 | 新网络无需 CPU/装配室；旧设备和旧保存结构保留兼容，不能强拆带物品设备 |
| 合成终端重新合并存取与制作 | 2026-10-18 用户在预览后明确授权实施安装；标题“终端”，铜短剑表示母分类全部，普通左键拿起物品、悬停 R 打开原有配方子页，连续两次点击拿起再存回；旧访问设备继续兼容（0.27.4 按最新要求覆盖此前左键查看配方的行为） |
| 网络策略按持久成员关联 | 几何锚点变化或网络合并/拆分不能静默丢失授权和锁定 |
| 服务器执行真实业务，客户端发送意图 | 回包须完整验证、匹配事务及读取代次；显示缓存不承担权威扣账 |
| 存储总线不硬接第三方容器 | 没有通用接口，强依赖与脆弱反射不符合已确认范围 |
| 特殊合成回调安全拒绝自动执行 | 无法表达为存储事务的副作用不能通过忽略回调解决 |

## 已排查过的坑

| 问题 | 有效处理或当前边界 |
| --- | --- |
| 使用另一套存档或用 `-nosteam` 测加载 | 改用实际存档目录并保留 Steam 发现；服务端仍跳过纯客户端模组 |
| 仅传模组名构建或在错误目录运行 | `-build` 传源码完整路径，在安装目录执行，核对产物时间与大小 |
| 服务端通过但客户端缺贴图/UI 崩溃 | 补静态资源和实际客户端验证，分别报告证据 |
| 旧坐标数字类型导致角色加载异常 | `TagCompat` 读取原始数值并兼容转换；保留旧字段读取 |
| 配方数组重排后索引指向错误 | 最终索引在 `PostSetupRecipes` 重建，不能只信早期加载索引 |
| 只按物品编号存储、部分存入清空整格 | 使用完整身份和余量守恒；加载旧数据不按新容量截断 |
| 合成先扣料、再遇到输出/条件失败 | `StorageTransaction` 准备和复核后整体提交；0.26.1 支持空间不足时逐批尝试 |
| 多 CPU 被首队列阻塞、取消或撤权后继续旧任务 | 轮转候选，保存真实所属任务；执行前重新验证状态和权限 |
| 过期/重复/截断游标回包覆盖手持物品 | 0.26.1 增强事务号、去重、身份与完整解码检查 |
| 无权限玩家收到管理数据、截断快照局部替换 | 按接收者权限发送，完整校验后发布，撤权清陈旧状态 |
| 多格设备子格不能被远程绑定/箱子解析识别 | 使用规范类型与原点；不能仅按旧单格 TileType 判断 |
| 上传连接重置与 CLI EOF | 重试前核对远程提交；曾用 HTTP/1.1 或 CLI 禁用 HTTP/2 成功，尚未确认确切根因 |
| Windows Git 的 schannel TLS 握手失败 | 2026-10-15 使用单次命令 `git -c http.sslBackend=openssl -c http.version=HTTP/1.1` 推送并查询远程成功；未关闭证书校验、未更改全局 Git 配置；确切网络根因未确认 |

旧版交付记录提供问题背景，不自动证明当前版本或新环境的全部路径已通过。
