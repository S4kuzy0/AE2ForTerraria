# 从一个最小 ME 网络开始

先在自己的测试世界或存档副本体验；完整设备名称、配方与容量以当前游戏和 [玩家指南](../AE2ForTerraria/README.md) 为准。

1. 安装并启用模组，进入世界，按 Tab 打开物品浏览器。搜索原版材料，查看配方、用途和获取分组；尚未建模的第三方条件可能显示未知。
2. 准备磁盘驱动器、存储磁盘、线缆和合成终端。把驱动器与终端通过线缆连接，向驱动器放入磁盘。
3. 打开终端，从原版背包存入少量材料，再取回一部分，核对剩余数量。词缀和自定义数据仍按实际身份保留。
4. 在终端选择一个简单配方，先看缺料与工作站要求，补齐后制作。特殊动态合成可能需要手动处理，不能略过其门槛。
5. 容量接近上限时尝试扩容，再按需设置分区、收集器过滤、无线桥接或权限。清楚区分关闭界面、拆除设备与移除磁盘的行为。

本文件是可照做的操作示例，不提供个人世界存档、提取的游戏图像或虚构实机截图。历史实际场景与未覆盖项目见 [维护手册](maintenance.md)。
